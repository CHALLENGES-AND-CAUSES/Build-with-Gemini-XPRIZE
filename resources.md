# Build with Gemini XPRIZE Resources

This document outlines the available resources, support channels, and important media for the hackathon.

## Getting Started (Credits)
* **Google Cloud Free Trial / Credits:** A 90-day program that lets new users try popular Google Cloud products without any financial commitment. XPRIZE registrants get a $300 Google Cloud Credit. Access the standard trial here: [https://cloud.google.com/free](https://cloud.google.com/free)
* **Antigravity Plan:** Antigravity includes a $0/month plan to help you build. Access it here: [https://antigravity.google/](https://antigravity.google/)
